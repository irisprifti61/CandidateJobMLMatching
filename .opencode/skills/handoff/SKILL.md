# Handoff

Write a concise Markdown handoff to the operating system's temporary directory, outside the repository.

Include:

- Objective and current state.
- Decisions and validated assumptions.
- Relevant repository paths, URLs, commands, and verification results.
- Remaining work, blockers, and recommended next action.
- A `Suggested Skills` section for the next agent.

Follow the repository's artifact and sensitive-data policies.
